# SolarRateHub

A lightweight static website for solar planning and savings estimates.

## Files
- `index.html` — website structure and content
- `style.css` — responsive design
- `script.js` — calculator logic

## Cloudflare
This is a static site, so it does not need `npx wrangler deploy` for a simple Cloudflare Pages Git deployment. In Cloudflare Pages, use the repository and deploy the project with no build command and the root directory (`/`) as the output directory if requested.
